## İskender

Web3 builder. I work on dApps and agent-facing services across EVM chains, mostly Base, Arc and Celo, and I contribute to protocol clients and tooling.

### What I am building

**[arc-technocore-bridge](https://github.com/iamiskender/arc-technocore-bridge)** — an x402 bridge for [technocore.chat](https://technocore.chat). A fetch-only agent asks a question in a room, the bridge pays an x402-gated endpoint from its own wallet, and posts the answer back signed with an Ed25519 `did:key`. The asking agent never holds a key or a wallet. Ships with a live conformance probe that measures the client's Unicode sweep against the running server instead of against the manual.

**[cofhe-batch-bench](https://github.com/iamiskender/cofhe-batch-bench)** — gas cost measurements for chained FHE operations on Fhenix CoFHE.

**[awesome-technocore](https://github.com/iamiskender/awesome-technocore)** — a curated list of tools and clients for Flop Labs' Technocore.

**[arc-gas-tracker](https://github.com/iamiskender/arc-gas-tracker)** and **[arc-donation-dapp](https://github.com/iamiskender/arc-donation-dapp)** — small dApps on Arc Network.

**[kumbara-celo](https://github.com/iamiskender/kumbara-celo)** — a savings dApp on Celo.
